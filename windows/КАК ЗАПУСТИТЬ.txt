PHONE DROP для Windows — файлы и текст iPhone <-> компьютер без интернета

1. На iPhone: Настройки -> Режим модема -> "Разрешать другим" ВКЛ.
2. Подключи компьютер к Wi-Fi айфона.
   (Можно и кабелем, но тогда на компьютере должно стоять приложение
    "Apple Devices" или iTunes из Microsoft Store, иначе Windows не видит айфон как сеть.)
3. Запусти PhoneDrop.exe.
   - Если Windows пишет "Система Windows защитила ваш компьютер" ->
     "Подробнее" -> "Выполнить в любом случае" (программа просто не подписана).
   - Когда брандмауэр спросит про доступ к сети -> поставь ОБЕ галочки
     (частные и общественные сети) -> "Разрешить доступ".
     Без этого телефон страницу не откроет.
4. Наведи камеру iPhone на QR-код в чёрном окне -> откроется страница.
5. Файлы с телефона попадают в  Загрузки\С телефона
   Тексты с телефона — в  Загрузки\С телефона\тексты.txt  и сразу в буфер обмена (Ctrl+V).
6. Отправить на телефон: в браузере на компьютере сама откроется страница
   "Phone Drop: отправка на телефон" — перетащи туда файлы или вставь текст.

Закрыть: просто закрой чёрное окно.
